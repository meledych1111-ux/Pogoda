# 👤 Руководство пользователя

## Что это за приложение
Это веб‑приложение, которое:
- показывает текущую погоду в Севастополе (через Open‑Meteo API),
- даёт совет, что надеть при такой температуре,
- позволяет ввести, что вы реально надели,
- даёт возможность оценить:
  - насколько совет был точным,
  - насколько ваш выбор одежды оказался удачным,
- сохраняет историю и строит статистику.

## Как пользоваться
1. Откройте страницу в браузере (файл `index.html`).
2. Вверху появится текущая температура и совет по одежде.
3. Оцените совет кнопками **«Совет подошёл / не подошёл»**.
4. Введите, что вы надели (например: *куртка и джинсы*).
5. Оцените свой выбор кнопками **«Подошло / Холодно / Жарко»**.
6. Нажмите **«Сохранить»**.
7. Внизу появится история ваших записей и сводная статистика.

## Где хранится история
Все данные сохраняются **локально в браузере** (LocalStorage).  
Это значит:
- история не пропадёт при перезагрузке страницы,
- но она не синхронизируется между устройствами.
