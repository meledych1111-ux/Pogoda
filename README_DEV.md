# 👨‍💻 Руководство разработчика

## Структура проекта
- `index.html` — разметка интерфейса.
- `style.css` — стилизация (адаптивный дизайн, кнопки, блоки).
- `script.js` — логика:
  - загрузка погоды через Open‑Meteo API,
  - генерация совета по температуре,
  - сохранение данных в LocalStorage,
  - отрисовка истории и статистики.

## Основные функции
- `loadWeather()` — получает погоду и формирует совет.
- `saveRecord()` — сохраняет запись (совет, выбор, оценки).
- `renderHistory()` — отображает историю.
- `renderStats()` — считает статистику и показывает её.

## Логика советов
- `< 0°C` → зимняя куртка, шарф, шапка.
- `0–9°C` → тёплая куртка или толстовка, джинсы.
- `10–15°C` → лёгкая куртка или толстовка, джинсы.
- `16–17°C` → куртка и джинсы (футболки с кофтой мало).
- `18–19°C` → футболка днём, лёгкая куртка вечером.
- `20+°C` → лёгкая летняя одежда.
